命令：`python3 -m unittest discover -s tests -p test_m01_01_pm_demo.py -v`。使用项目既有Node24.22.1和jsdom30.1.2，不新增依赖，不新建浏览器环境。4项作者测试通过：

| 检查 | 实际范围 |
| --- | --- |
| 模型边界与恢复 | 299秒可验证、300秒过期；29秒不可重发、30秒可重发；当前码/旧码、错误/不足位、请求/验证失败恢复、改邮箱、取消及新账号资料边界 |
| 实际DOM事件 | jsdom加载最终自包含HTML，点击/输入/提交完成访客、非法邮箱、错误码、已有账号成功、过期→重发→新账号资料交接路径；读取页面上的来源mealId和零业务写入 |
| 源与预览一致 | 内嵌CSS/脚本与源及生成方式逐字节一致；不依赖ES module/file协议跨文件加载；无网络、浏览器持久化或外部资源 |
| 需求/产物修订 | 固定文件SHA256与本批/修订一致，UX/RD/QA未启动 |

本批起草时在尚未生成manifest的中间状态运行测试，清单测试因文件缺失失败，其余检查通过；补齐固定清单后4项完整重跑通过。未将缺失文件时的中间执行称为交付通过。
