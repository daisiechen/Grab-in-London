## 用户目标、入口与完成结果

使用者为希望离开Fancy的账号本人。入口是本人Settings中的Delete account；从看清影响、可取消、重新认证、主动提交，到同步撤权屏障、后台删除处理、无需业务登录的最小回执查询与异常支持出口，形成一次完整旅程。终点是用户能看到真实处理结果或明确获得支持途径；不是一个按钮、202、邮件编辑器或供应商接受请求就称已删完。

## 正常路径与取消

1. 本人进入删除说明：明确将退出登录、隐藏公开资料/内容、取消未开始主持场次、退出未开始参与和待审申请、撤联系/群区间、清AI偏好/活跃会话；已开始饭局的其他成员资格保留。剩余供应商及物理清理仍会继续，最小保留按批准政策，不杜撰期限。
2. 用户可Keep my account取消，未提交不改变任何业务事实。决定继续时对既有身份重新认证；邮箱、Google/Apple按已绑定身份原流程，不新建另一会话家族代替本人再认证。
3. 提交前校验5分钟内的有效reauth、当前身份和版本。过期返回同删除意图再认证，不自动提交。Demo邮箱代码123456仅评审模拟，错误码不接受；绑定供应方及MFA/会话实际校验为后续真实接入。
4. 本人明确确认删除影响并主动Request account deletion；客户端在请求前预存256-bit随机receiptToken于安全存储，服务端只保存哈希，避免成功响应丢失后失去查询凭据。Demo只用内存合成receipt表达该时序，不假称生产安全存储已实现。
5. 服务端同步屏障全成功才202受理。成功后关闭业务会话，进入最小回执页，显示PENDING而非COMPLETED。每次后续状态查询仅凭私密receipt，不恢复或新建业务登录。
6. 后台按步骤幂等完成供应商撤销、正文清理/去标识、关联/事件/快照及预生成CSV清理、批准的最小保留与恢复策略，真实状态依次可为PROCESSING、NEEDS_SUPPORT、COMPLETED。部分已完成步骤保留，失败只重试未完成步骤。
7. 丢失202响应先使用预存receipt查询原次；结果未知不能发起第二个删除、重新注册或恢复业务权限。只有所有必需步骤完成才最终COMPLETED。

## 同步受理屏障：不允许延期执行的内容

同一同步事务按既有锁顺序、权威DB时钟与生命周期补齐规则执行，事务失败全部回滚，不先202让延迟worker决定是否赶在开始前退出。

| 同步项目 | 成功前必须完成的不变量 |
| --- | --- |
| 身份与账号 | 重认证/本人/版本通过，账号转DELETING，全部业务session撤销，其他命令不能穿过删除屏障 |
| 联系及群 | 撤清该人对双方同意，关闭其当前group授权区间；历史授权与未来写权限分别判断，不扩大其他人读取 |
| 未开始饭局 | 主持场取消、本人confirmed席位退出、本人pending同步撤回；临界开始时间用锁内当前时点重验 |
| 已开始饭局 | 不抹除开始事实和其他成员资格，不用删除改写既有成团/取消原因 |
| 公开投影 | 立即不返回本人公开身份/内容，不能等物理purge完成后才隐藏 |
| 隐私及统计 | privacy epoch递增、受影响旧snapshot整份撤销、旧导出和旧明细拒读；查询/下载逐次检查 |
| AI生命周期 | 偏好、活跃上下文及引用旧偏好的缓存失效，epoch/generation使旧卡片、草稿和迟到模型回复不可回填；不让日志重建画像 |
| 原子提交 | 删除记录、供应商/清理作业、必要通知/outbox与上述状态同事务；失败零部分受理 |

不等于同步物理清库或删除他人消息/资格；物理正文清理、供应商撤销、依法最小保留与备份恢复按批准策略异步执行，未批准真实政策不得接真实用户。

## 最小回执、失败与恢复

| 状态/情况 | 本人看到什么、下一步 |
| --- | --- |
| 校验/重认证失败 | 未受理，返回认证/确认，保原意图；无删除写入 |
| 同步屏障失败 | 明确未接受、账号保持原状；同意图可重试，不把一半撤权显示成功 |
| PENDING | 请求已接受、会话与新参与/联系停止，仍有剩余删除步骤 |
| PROCESSING | 明确正在处理，逐步结果准确；不把提供方接受等同最终清理 |
| NEEDS_SUPPORT | 说明需要支持，已完成步骤不回滚，账号不因此复活 |
| COMPLETED | 全部必需步骤确实完成，仍不恢复账号/业务会话 |
| 响应丢失/查询暂失败 | 先查原receipt，保持凭据；重复查询不创建第二个请求、不重复业务取消 |
| receipt过期/丢失/不可用 | 未登录可联系公开支持，显示可复制完整邮箱；不要求注册或登录后才有出口 |

正式receipt仅返回最小PENDING/PROCESSING/COMPLETED/NEEDS_SUPPORT等进度，不返回个人资料或他人事实。receiptToken不进URL、日志、分析、邮件预填或公开参考号；公开reference只是定位线索，不作为读取私密数据、修改删除状态或恢复账号的授权。
