<a id="goal"></a>
## 1. 目标与自然路径

账号本人希望维护愿意公开的介绍、调整隐私/可选统计和明确保存的AI偏好，并知道保存是否生效。入口为本人Profile/Settings及My preferences；已登录身份只代表本人，不获得其他人的资料写权。

从当前公开资料进入编辑→保留原值作为草稿→选择保存或取消→读取权威结果并返回公开主页；设置中的统计选择和AI偏好独立保存；需要离开时确认退出并回访客。完成点是确认值可找回、失败/冲突可处理，不是开关/字段看起来变了。

本包不做新注册、账号删除、产品问卷内容、头像上传扩展、其他人的资料编辑、新隐私管理平台或隐藏画像；引用J01身份门槛、J06问卷、J08删除，不替它们关闭验收。

<a id="profile"></a>
## 2. 公开资料的查看、编辑和返回

- 姓名2–40字符、简介trim后20–1000字符，生活状态、至少一种交流语言和至少一个兴趣沿既有字典必填；职业/学校/家乡可选，不索取证明。
- 明示公开字段；邮箱/凭据、AI偏好、私评分/问卷、单方再约和消息不出现在他人的公开主页。公评仅展示按J04发布条件生效的文字，不伪造信誉星级。
- 编辑只改变草稿，取消恢复最近确认值。合法保存后本人及公开投影一致；非法长度、缺项保稿并指明需修正内容。
- 服务失败不显示已保存；跨设备版本冲突先读权威版本，保留本人的提议并让本人核对、确认后重新保存；不得静默覆盖另一设备。退出/切账号后丢弃旧响应，不把前账号私密稿搬给后账号。

<a id="privacy"></a>
## 3. 隐私、可选统计与退出

设置解释公开介绍、群聊/互选与私密反馈边界，拉黑对象及解除沿J04有效同意规则，不因设置页解除就恢复私聊。选择可选统计的开启/关闭仅按真实保存结果显示；未保存、失败、离线不显示服务端已更新，后续重进须读取确认值。当前可选统计原观察必须在真实目标环境核对，不用本模拟关闭旧问题。

退出前可取消；确认清本机私密会话、临时AI上下文/对话和未提交账号内存，停止旧轮询/旧写入，回访客入口。退出不删除账号已确认的持久偏好，不是删除账号。服务端撤销失败时仍如实说明并清本机凭据，不伪称远端全完成；真实会话/安全存储另验。

<a id="preferences"></a>
## 4. AI偏好明确确认、替换与删除

允许字段：区域、预计人均预算上限、含host总人数、host声明的饮食、交流语言、氛围。日期/具体时刻只作本次查询；不从Profile兴趣、评分、聊天或一次查询自动建画像，不把饮食推断为健康或宗教。真实允许值用批准字典：菜系EUROPEAN/JAPANESE/SPANISH/CHINESE（若适用）、饮食VEGETARIAN_OPTIONS/VEGAN、氛围EASY_CONVERSATION/FOOD_DISCOVERIES/TRAVEL_CULTURE及既有语言code。界面用自然语言标签。

My preferences是唯一查看/替换/删除入口。自然语句先列待确认变更，只有本人Confirm and remember或明确Save后才生效；普通查询不保存。记录允许字段、version、confirmedAt和本人确认来源，不保存整段对话作记忆。账号偏好按userId持久、其他iOS会话读同版本；游客仅当次内存，登录不自动迁入。

保存/替换失败保留提议，不报记住；409读最新权威值，展示旧提议与新值，复核后用新版本提交，不静默覆盖。删偏好失败可重试，成功立即停止各活跃会话使用旧值，清引用旧偏好的助手上下文/候选；原业务编辑器未发文字与已提交业务不被删除，也不承诺撤回外部已发内容。模型停用不能阻止偏好读取/删除。

<a id="clear"></a>
## 5. soft/hard、CLEAR及生命周期关联

已确认偏好只参与soft排序，不自动过滤；本次明确修改＞本会话已确认＞已应用Discover字段组成hard。例：偏好£35但本轮只问Soho，£45仍可出现在后；明确预算£35才过滤。明确“any budget／不限预算”CLEAR硬预算并抑制对应旧soft，下一轮不自动恢复；“任何区域”同理，不反向改Discover筛选。

New conversation清当前设备会话/临时条件和助手未发送文字，保留已确认账号偏好及原业务编辑器草稿；30分钟闲置重启保留偏好与未发文字。设备对话不跨设备同步；偏好删除、账号切换、清会话使旧请求/旧编辑器响应失效，不能插入新会话或自动写业务。J01/J02/J03负责各自查询/转入实测，J08清除账号偏好/会话。

真实AI需要供应方数据许可、最小上下文、人民币50元/月硬闸及原真实模型/数据/费用评测；本包偏好表单不触发模型，不把本地模拟宣称跨设备真实保存。

<a id="demo"></a>
## 6. Demo及验收

自然入口是合成本人主页，可编辑/取消/保存，进入Settings调整统计、My preferences或退出。偏好可修改后Confirm、删除前确认、触发另一设备冲突后看最新值及提议；CLEAR后再次查询展示条件仍清除。评审区独立注入失败/冲突、New conversation/30分钟闲置，状态行核对原编辑器文字保持。所有资料/偏好只在当前页面内存，刷新重置，不访问真实服务。

- J05-AC01：公开字段编辑与取消、长度/必填、失败保稿、保存结果和公开展示一致。
- J05-AC02：权限/隐私与可选统计选择准确，未保存不作保存，其他人私密信息不出现。
- J05-AC03：偏好只有明确确认才保存/替换，409加载权威值后本人再确认；删除使旧引用失效但不改业务稿。
- J05-AC04：soft不作hard，CLEAR在后续轮次不恢复；New/闲置/退出按规则处理偏好、会话和原编辑器。
- J05-AC05：退出可取消，确认后不再显示私密内容，不等于删号或删除持久偏好。
