# Fancy MVP分批功能范围

需求修订：r04｜本版：iOS App和管理后台｜移动Web后续。

本附件说明每一小批为产品使用者增加什么、哪些相邻功能暂不在该批，以及什么结果算完成。它不表示功能从零开发，也不表示每批都单独上线。既有有效功能与证据保留；模块业务规则仍见各模块说明。前提只列需要先可用的功能，执行人员、工作包、环境及取证见独立项目管理方案。

M01—M12为模块，D01—D19为较大的需求追踪范围，M01-01等为具体小批；编号不改变业务权限。标为后续的移动Web功能不在本版，未安装App邀请路径不被假定已经确定。

## M01 账号与个人资料

<a id="m01-01"></a>

### M01-01 访客入口与邮箱登录

所属范围：D01；本版iOS。可用前提：基础服务与访客/本人身份入口。

- 本批做：欢迎页先浏览；邮箱验证码登录/取消/失败；返回入口意图保持且不代做动作。
- 本批不做：Google/Apple、首次资料表单、资料编辑、设置；发现结果本身归M02。
- 完成结果：本人能邮箱登录或取消成为访客；错误/过期不绕过认证，原意图未被执行。

<a id="m01-02"></a>

### M01-02 Google登录

所属范围：D01；本版iOS。可用前提：M01-01。

- 本批做：Google授权、取消、失败与已有身份回流；不自动合并同邮箱身份。
- 本批不做：Apple、资料表单、业务申请和新增身份管理界面。
- 完成结果：Google登录成功/取消/失败可区分，返回原意图且不自动绑定身份。

<a id="m01-03"></a>

### M01-03 Apple登录

所属范围：D01；本版iOS。可用前提：M01-01。

- 本批做：Apple授权、取消、失败及iOS回调回流，沿用统一身份边界。
- 本批不做：Google改版、资料表单、分发/上架与新身份平台。
- 完成结果：iOS Apple登录回调和取消可恢复，旧请求不产生另一账号会话。

<a id="m01-04"></a>

### M01-04 首次资料与参与门槛

所属范围：D01；本版iOS。可用前提：M01-01。

- 本批做：新用户必填公开资料、年龄/社区确认、长度校验、失败保稿；完成后回原入口。
- 本批不做：修改既有资料、头像上传扩展、自动申请、设置和删除。
- 完成结果：缺项阻止参与；合格资料能保存，回流后仍需本人主动业务提交。

<a id="m01-05"></a>

### M01-05 公开主页与本人资料编辑

所属范围：D01；本版iOS。可用前提：M01-04。

- 本批做：公开主页必要字段、本人编辑/取消、成功更新、失败保稿与版本冲突。
- 本批不做：首次注册重做、公开信誉分、饭后评价内容和新头像上传。
- 完成结果：本人编辑与公开展示一致，取消不改值、失败保稿、其他账号不能修改。

<a id="m01-06"></a>

### M01-06 基本设置、可选统计与安全退出

所属范围：D01；本版iOS。可用前提：M01-01、M01-04。

- 本批做：既有设置/可选统计选择的保存与恢复、退出和会话失效清理、入口分流。
- 本批不做：问卷内容、删除作业、AI偏好、通知订阅；尚未可用的关联入口不可假称完成。
- 完成结果：设置显示权威保存结果，退出后无旧账号回填；保留可选统计持久性观察直到实际关闭。

## M03 发起饭局与管理安排

<a id="m03-01"></a>

### M03-01 创建草稿与选店

所属范围：D03；本版iOS。可用前提：M01-04。

- 本批做：四步创建草稿容器；查找并确认餐厅、照片/署名适用规则、返回/替换保留。
- 本批不做：发布、日期人数校验展开、预算声明、平台订位库存。
- 完成结果：可确认真实餐厅并保存到创建草稿；搜索失败/空结果不清除既有选择。

<a id="m03-02"></a>

### M03-02 日期、时间、人数与截止

所属范围：D03；本版iOS。可用前提：M03-01。

- 本批做：安排输入和伦敦DST选择、minimum/capacity/截止关系、步骤切换保稿。
- 本批不做：发布、审批、自动成团/取消、餐厅新能力和预算步骤。
- 完成结果：不存在时间拒绝，重复时间明确选择；人数/截止错误可修正且不丢草稿。

<a id="m03-03"></a>

### M03-03 介绍、费用声明与发布

所属范围：D03；本版iOS。可用前提：M03-02。

- 本批做：介绍/预算/外订声明、Review主动确认、发布及未知结果找回。
- 本批不做：已发布编辑、审批、退款、自动订位、AI预填和生命周期任务扩展。
- 完成结果：从既有草稿发布唯一饭局，字段及声明准确，失败保稿且重试不重复创建。

<a id="m03-04"></a>

### M03-04 编辑安排与首次批准后的锁定

所属范围：D03；本版iOS。可用前提：M03-03、M04-02。

- 本批做：无人获准前编辑/未知恢复、批准后永久锁定、声明人数变化待更新及重申明。
- 本批不做：取消重建整条旅程、重新审核、截止自动作业和群设置。
- 完成结果：可编辑阶段保存有效；审批竞态拒绝旧修改并保稿；人数变化要求更新声明。

<a id="m03-05"></a>

### M03-05 主动取消整场

所属范围：D03；本版iOS。可用前提：M03-04、M04-03。

- 本批做：host确认/返回、原因、关闭待审/通知目标、终态及保留聊天授权事实。
- 本批不做：平台退款、自动重开/搬迁、群解散和自动人数不足判定。
- 完成结果：确认前可退出；确认后全场状态一致且不可复活，群身份不被错误删除。

<a id="m03-06"></a>

### M03-06 截止、最低人数与开始资格

所属范围：D03；本版iOS。可用前提：M04-03、M03-05。

- 本批做：截止停止申请/审批、待审过期、人数不足/开饭前跌破最低取消、开始资格冻结。
- 本批不做：自助饭后表单、人工出席纠错、群只读或计划外生命周期新规则。
- 完成结果：精确截止/开始边界与成员历史一致，迟到执行不跳终局，开饭后不再取消掩盖事实。

## M04 申请参加与成员管理

<a id="m04-01"></a>

### M04-01 申请、待审与撤回

所属范围：D04；本版iOS。可用前提：M02-03、M03-03、M01-04。

- 本批做：申请留言/门槛/同意、提交/原意图查询、Pending展示、主动撤回及规则内重申。
- 本批不做：主持审批、确认席位退席、群聊、AI草稿。
- 完成结果：申请可追踪且Pending不占位，撤回正确，失败/满员/截止保稿不重复提交。

<a id="m04-02"></a>

### M04-02 主持审核与最后名额

所属范围：D04；本版iOS。可用前提：M04-01。

- 本批做：读申请及公开主页、批准/拒绝、原子名额/截止校验、确认及最小入群授权事件。
- 本批不做：群消息界面、退席、外订声明编辑、安排改动和付款保留。
- 完成结果：批准直接确认、拒绝本场不能重申，最后席位并发不超额；入群权限事件准确。

<a id="m04-03"></a>

### M04-03 退席与新轮次申请

所属范围：D04；本版iOS。可用前提：M04-02。

- 本批做：开饭前退出释放席位、允许时新轮次重申、历史保留和Meals当前状态。
- 本批不做：退群、整场取消、自动搬迁、已开始出席纠错。
- 完成结果：退席与再次申请轮次清楚，旧状态不覆盖新轮次，群资格不因退席自动删除。

- 完成结果：打开聊天不等于全读，真正可见才更新；群读取不自动把通知列表标读。
