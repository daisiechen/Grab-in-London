## 复现

在仓库根目录使用已配置的 bundled Python 运行 `scripts/business_model.py` 和 `scripts/render_business_report.py`；使用 bundled Node 运行 `scripts/build_business_artifacts.mjs`。脚本使用本机已安装的 Codex 运行时路径，不需要业务密钥。运行时路径变化时应重新解析依赖。

`build/` 下的渲染、校验和中间文件不提交；输出目录仅保留交付文件。已存在的竞品主报告未提交修改予以保留，不纳入本轮提交。
