# 状态、权限与返回恢复

同一页面内的外部事件评审层不属于用户操作。固定样例不代表任意输入已测。

## J07

|场景|权限/状态|返回/恢复|交互边界|
|---|---|---|---|
|举报|登录本人对成员私密举报，原因必填，说明可空|空原因就地校验；取消不提交；受理后返回本人记录|受理不等调查完成；响应丢失先查原次结果，防重复|
|支持状态|他人不可见举报；内部处理权限仅支持端|IN_PROGRESS/回复由外部支持事件产生，独立评审层展示|检查状态仅刷新当前状态，不伪造处理完成；真实通知投递未测|

## J08

|场景|权限/状态|返回/恢复|交互边界|
|---|---|---|---|
|申请前|登录本人→影响说明→再认证→最终本人确认；确认无默认|取消返回Settings且不提交；验证码123456仅固定演示输入|真实验证码、会话/重认证/限流未接入|
|受理后|受理不等删除完成；同步关闭账号访问，不返回账号页|保存最小私密回执；响应丢失检查原次；PENDING/PROCESSING/NEEDS_SUPPORT/COMPLETED由外部worker|未登录可凭原回执查进度和联系支持；COMPLETED仅所有必要步骤成功|
|公开支持|公开参考号不具私密授权能力；邮箱全文只读可手动复制|mailto仅地址，不带token/回执/query；打开编辑器不等发送|复制/系统邮件/安全存储/供应商撤销及物理清理未实测；失败不声称完成|
