# 状态、权限与返回恢复

同一页面内的外部事件评审层不属于用户操作。固定样例不代表任意输入已测。

## J03

|场景|权限/状态|返回/恢复|交互边界|
|---|---|---|---|
|正常|当前成员可看名册/发送；退出群不等于退出饭局|Inbox→群聊→设置→确认退出→Left group→获授权历史；取消返回群设置|固定手写样例与AI草稿分别发送，草稿转入不自动发送|
|只读/失败|仅明确退群/解散/账号撤权关闭相应写区间与实时名册；退席、饭局取消/结束、外订失败不自动关闭仍获授权群；重入按服务授权重新判定|失败保留未发送文本，重试避免重复；读位只在实际可见消息推进|通知开关影响通知展示，不抹去Inbox事实；真实推送/读位/跨设备仅状态合同|
