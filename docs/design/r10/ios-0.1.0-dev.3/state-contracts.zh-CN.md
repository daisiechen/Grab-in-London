# 状态、权限与返回恢复

同一页面内的外部事件评审层不属于用户操作。固定样例不代表任意输入已测。

## J03

|场景|权限/状态|返回/恢复|交互边界|
|---|---|---|---|
|正常|当前成员可看名册/发送；退出群不等于退出饭局|Inbox→群聊→设置→确认退出→Left group→获授权历史；取消返回群设置|固定手写样例与AI草稿分别发送，草稿转入不自动发送|
|只读/失败|离群/饭局终态不发新消息、不展示实时名册；重入按服务授权重新判定|失败保留未发送文本，重试避免重复；读位只在实际可见消息推进|通知开关影响通知展示，不抹去Inbox事实；真实推送/读位/跨设备仅状态合同|

## J04

|场景|权限/状态|返回/恢复|交互边界|
|---|---|---|---|
|正常|本人报告出席，评分无默认；私评分/公开短评/私密选择为独立对象|逐项回执；部分成功仅重试未存项；取消不撤销已存项|WAITING只允许修改本人私密选择，不暴露对方、不显示OPEN私聊|
|互选/恢复|真实OPEN才可发私聊；撤回需本人确认，历史只读|拉黑/撤回关闭发信；解除拉黑不复活旧同意，需新互选|他人选择为独立评审层前置，不是用户推进按钮；公开编辑/删除传播由合同规定|

## J06

|场景|权限/状态|返回/恢复|交互边界|
|---|---|---|---|
|独立问卷|Settings独立入口，不要求出席、饭后或七天|再次使用和多原因独立可选；可只存原因；空提交不产生记录|返回保留规则按PRD；保存更新最新记录，失败保留草稿；清空某题不清空另一题|
