# support-0.1.0-dev.1 独立测试计划

本文件是方案准备，不是产品QA通过报告。设计签收由总PJ独立完成；真实服务与实现当前未启动。每条证据绑定候选SHA、build、接口版本、迁移、环境与合成夹具版本，缺一不签真实联调。

|用例|检查对象|通过条件|
|---|---|---|
|S01|原报告与资格|self absent/host present永久保留，当前有效absent；名单、未取消及expectedVersion权威校验|
|S02|连续7天UTC|19:59:59.999Z拒绝逾期追加，20:00:00.000Z可进入；仅校验窗不自动写入|
|S03|409恢复|加载本对象revision2，保留absent/原因；本人确认新CORR-2才写revision3，取消无写入|
|S04|幂等/未知|同意图超时先查原次；重复不增修订，不能以别对象revision推断成功|
|S05|仅回复|只保存本人可见结论，不制造CORR；不泄露私聊、他案、调查原文|
|S06|权限与失效|身份/MFA/case权限失效清事实/拒写；已知ID不授予读取权|
|S07|传播|仍absent继续不适用；旧asOf历史不覆盖，其他有效共同依据不误伤，撤回/拉黑不复活|

测试顺序：公开模块接口/纯规则→独立数据库命令与事务→本版真实客户端路径→受影响回归→具备真实上游后的定向联调。单测、mock、原型和真实服务分别记录；上游未实现只阻断对应联调。

环境先检查项目既有Node版本/锁文件、数据库可达、唯一端口/PID/CWD和本版合成夹具；不要每个小包重建整个环境。失败先分权限、合同、数据、候选与环境，再交唯一owner修复；不反复无目标重跑。

回归仅覆盖受影响消费者：Support→出席/再约/公评/分析；Admin1→分类/纠错/删除的快照读取；Admin2→Admin1查询与导出/隐私。无相应实现不声称联调通过。真实供应商、生产数据和部署需独立授权与发布门槛。

工程复验补充：最小事实DTO授权/错target拒读；caseVersion与attendanceVersion故意不同，纠错body expectedVersion和回复case If-Match分别检查；Unknown原POST重放；受限CLI本人确认/取消/保原因/不输出凭据，reply-only无CORR。CLI与事实API尚未创建，不冒称产品实现。
