以下来源用于方法研究，不是已安装依赖或权威认证。社区技能是可借鉴实现，不代表其全部流程均应采用。来源核查日期：2026-10-18。

| 来源 | 借鉴与限制 |
| --- | --- |
| [PM Skills Marketplace](https://github.com/phuryn/pm-skills) | 借鉴需求发现、假设、优先级、执行与验证的能力划分；不依赖其命令或安装方式。 |
| [Create PRD skill](https://github.com/phuryn/pm-skills/blob/main/pm-execution/skills/create-prd/SKILL.md) | 借鉴需求与价值、假设和版本范围的衔接；不照搬固定篇幅、强制章节或每次停下提问的流程。 |
| [Product Manager copilot](https://github.com/julianoczkowski/product-manager) | 借鉴市场问题到需求和交付的阶段关系；不把整套生命周期强加给局部任务。 |

维护时保留真正改变决策或改进工作的指导。通过现实任务检查：简单变更是否被不必要地扩展、复杂交付是否缺少关键规则、假设是否冒充事实、引用能否到达、是否混入业务事实或机器路径。修正已观察到的问题，不为假想场景无限追加强制步骤。
